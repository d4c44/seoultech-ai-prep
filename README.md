# Дайындық платформасы · AI Institute by Seoultech

Сайт для подготовки студентов **AI Institute by Seoultech**
(Қорқыт Ата атындағы Қызылорда университеті) к **рубежному контролю** и **сессии**.
Проект расширяемый: предметы, модули и контрольные добавляются по мере поступления материалов.

## Структура данных (data.js)

```
window.SUBJECTS = [
  { slug, name, ruName,
    modules: [ { id, title, questions: [ { n, kz, ru, answers, answer } ] } ] }
]
window.EXAMS = [
  { id, title, subtitle, subjects: [slug...], perSubject, total, variants }
]
```

- `answers` — количество правильных ответов (1/2/3, бейдж в UI)
- `answer` — правильный ответ (текст)

## Текущее содержимое

- **4 предмета × 25 вопросов** (100 всего), 1-модуль, 1-семестр 2026, вопросы KZ/RU
  - 🏛 Саясаттану · 🎭 Мәдениеттану · 🧠 Психология · 🌐 Әлеуметтану (в данных без эмодзи)
- **Рубежный контроль** (`rk-m1`): 4 нуски по 20 вопросов — 5 с каждого предмета,
  детерминированная выборка (seeded PRNG от id экзамена)
- **Ответы**: референсные, по стандартной программе дисциплин.
  ⚠️ Официальный ключ института перекрывает их: ответы живут в `tools/answers.json`
  (ключ `slug-номер`), правится/заполняется там, затем `node tools/build-data.js`.

## Как добавить новое

**Вопросы нового предмета/модуля:**
1. Текстовая выгрузка из Word (Word COM `Content.Text`, разделители `\r`).
2. Добавить предмет в `SUBJECTS_META` парсера при необходимости.
3. `node tools/build-data.js путь/к/выгрузке.txt`
4. Ответы — в `tools/answers.json`, затем повторный запуск парсера.

**Новый контрольный:** добавить объект в `EXAMS` (список предметов, по сколько вопросов,
сколько нусок) и пересобрать.

## Файлы

```
index.html            — разметка
style.css             — стили (editorial, без зависимостей)
app.js                — SPA: hash-роутинг (#/, #/e/<id>, #/e/<id>/v/<n>, #/s/<slug>[...]), экзамен, reveal-ответ
data.js               — данные (генерируется)
tools/build-data.js   — парсер выгрузки + answers.json → data.js
tools/answers.json    — правильные ответы (заполняется официальным ключом)
tools/test/smoke.js   — smoke-тест (jsdom)
```
