# AI Institute by Seoultech · Дайындық

Сайт для подготовки студентов **AI Institute by Seoultech**
(Қорқыт Ата атындағы Қызылорда университеті) к **аралық бақылау (рубежному контролю)**
и к **сессии**.

## Что умеет

- 📚 **Банк вопросов** — 100 сұрақ (4 предмета × 25), каждый на казахском и русском
- 🔍 Поиск и фильтры (все / знаю / повторить)
- ✓✗ **Отметки прогресса** — «Білемін» / «Қайталаймын», сохраняется в браузере
- 🎯 **Тест-режим** — случайные вопросы, самопроверка, список пропущенных для повторения
- 📊 Прогресс по каждому предмету и общий

## Структура

```
index.html      — разметка
style.css       — стили
app.js          — логика (SPA, hash-роутинг, без сборки)
data.js         — данные (генерируется, см. ниже)
tools/build-data.js — парсер Word-выгрузки (module.txt) → data.js
tools/test/smoke.js  — smoke-тест (jsdom)
```

## Как добавить предмет / вопросы

1. Положите текстовую выгрузку вопросов в файл (параграфы `\r` или `\n`).
2. Запустите:
   ```bash
   node tools/build-data.js путь/к/module.txt
   ```
   (при необходимости добавьте новый предмет в `SUBJECTS_META` в парсере)
3. Закоммитьте и запушьте `data.js` — сайт обновится сам.

## Тесты

```bash
cd tools/test && npm install && node smoke.js
```
