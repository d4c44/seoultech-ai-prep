# Рубежный контроль · AI Institute by Seoultech

Сайт для подготовки студентов **AI Institute by Seoultech**
(Қорқыт Ата атындағы Қызылорда университеті) к **рубежному контролю** и к **сессии**.

## Формат контроля

Один общий рубежный контроль по 4 предметам, 1-модуль, 1-семестр (2026):

- пул — **100 вопросов** (4 предмета × 25), каждый на казахском и русском;
- на экзамен берётся **20 вопросов** — кездейсоко, но **все 4 предмета обязательны** (по 5 с каждого);
- **4 нуски** (варианта) — выборка детерминированная: у нуски 1 всегда те же 20 вопросов (seeded PRNG), у разных нусок — разные;
- часть вопросов **множественного выбора**: бейдж «2 жауап» / «3 жауап» (в Психологии — 12 таких, в Мәдениеттану — 4).

## Разделы

- **Нуски** — экзамен: 20 вопросов, самопроверка (білемін / қайталаймын), итог с разбивкой по предметам и списком пропущенных;
- **Сұрақтар банкi** — все 100 вопросов по предметам: поиск, фильтры, отметки прогресса;
- **Практика** — рандомный тест по одному предмету (5/10/25).

Прогресс хранится в `localStorage` браузера студента.

## Структура

```
index.html            — разметка
style.css             — стили (editorial, без зависимостей)
app.js                — SPA-логика, hash-роутинг, нуски, экзамен
data.js               — данные (генерируется парсером)
tools/build-data.js   — парсер текстовой выгрузки Word → data.js
tools/test/smoke.js   — smoke-тест (jsdom)
```

## Как добавить предмет / вопросы

1. Выгрузите текст из Word (Word → COM: `Content.Text`, разделители `\r`).
2. ```bash
   node tools/build-data.js путь/к/module.txt
   ```
   Новый предмет добавьте в `SUBJECTS_META` парсера.
3. Многоответные вопросы: теги `<question2>`/`<question3>` в тексте или ручные аннотации `ANNOTATIONS` в парсере.
4. Коммит и пуш — Pages обновится сам.

## Тесты

```bash
cd tools/test && npm install && node smoke.js
```
